FeiJuchang

This build is based on open-source MAME4droid, maintained by FeiJuchang.

Editions

  • Basic FeiJuchang: stays close to stock MAME4droid; only necessary helpers (artwork key pack, one-tap ROM folder on the main screen).
  • FeiJuchang Mahjong (full): mahjong-focused extras — hide on-screen pad, universal mahjong keyboard (for games without a key pack), orientation-aware layouts, and more.
