# 透视皮肤按钮需求（rbmk）

右上角 Lua 色块**不能点**（点到的是下面的按键包皮肤，不是那块字）。  
要做得像「上分 / 杠 / 听」那样，必须做 **PNG 按钮**，写进 `artwork/rbmk/default.lay`。

快捷键保留：透视 Ctrl+9 或 F9；标记牌山 Ctrl+0；暂停仍是游戏里的 **F5**（按钮与 F5 同等效果）。

图放开发仓，测的时候 `deploy.bat` 会拷到 MAME 的 `artwork/rbmk/`（和牌图一样，不要手拷）。

---

## 放哪

| 阶段 | 路径 |
|------|------|
| 画图（Git 源） | `D:\Dev\arcade-mj-enhance\fei_mj_lamps\art\buttons\` |
| PC 测试 | `mame_current\artwork\rbmk\`（与 `kan_up.png` 同级） |

---

## 规格（跟现有绿键一致）

| 项 | 要求 |
|---|---|
| 格式 | PNG，透明底 |
| 推荐像素 | **142×130**（与上分/杠/听同尺寸） |
| 横版 | 皮肤会压成约 142×75，源图仍做 142×130 |
| 每钮两张 | 弹起 `*_up.png`，按下 `*_down.png` |
| 文件名 | 全小写英文，不要中文文件名 |
| 文字 | 画在图上（中文），不要靠 MAME 排字 |

---

## 必做 6 张

| 文件名 | 按钮上写什么 | 作用 |
|--------|----------------|------|
| `peek_up.png` | 透视 | 开/关透视面板 |
| `peek_down.png` | 透视（按下） | 同上 |
| `mark_up.png` | 标记牌山 | 把当前 ● 行标成「玩家摸」（同 Ctrl+0） |
| `mark_down.png` | 标记牌山（按下） | 同上 |
| `pause_up.png` | 暂停 | 暂停/继续（同 F5） |
| `pause_down.png` | 暂停（按下） | 同上 |
| `continue_up.png` | 继续 | 暂停后暂停键换成这张（已接） |
| `continue_down.png` | 继续（按下） | 备用 |

建议配色：透视偏黄、标记偏蓝、暂停偏灰，和麻将绿键能分开。

已用 PNG 替换色块占位。改图后 `deploy` 并重开游戏。

---

## 点哪里

**横屏**：透视、暂停在右栏「得分/碰/杠/听/胡」**上面**（和杠听胡同一边）。  
**竖屏**：透视、暂停在碰/杠那一行两端空位。  
**标记牌山**：开透视后，窗口标题栏右侧（同 Ctrl+0）。

电脑鼠标也能点（已绑成真正的皮肤按键，不是只能手机）。
