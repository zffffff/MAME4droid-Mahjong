## 产品理念

两款分工不同，不是「残缺版 vs 完整版」：

| | 基础飞剧场 | 飞剧场怀旧麻将（进阶版） |
|--|--|--|
| **主旨** | **尽量与官方原版体验一致** | **在麻将场景上锦上添花** |
| **改动原则** | 只做**非常有必要**的体验优化，降低入门难度 | 为愿意投入、想把麻将玩得更顺的人提供积极反馈 |
| **给谁** | 第一次碰、怕改乱、只想少踩坑的玩家 | 经常玩街机麻将、愿意为更好手感升级的玩家 |

**基础版**像「官方 + 扶一把」：打开就是官方风格游戏列表；自动装好麻将按键图（artwork）、主界面 📁/🖼 小按钮减负；中文机种名在**第二次冷启动**后出现；帮助里能找到官网与开源说明（灯控等进阶能力在进阶版）。  
**进阶版**像「官方 + 专为麻将打磨」：自制选台首页、藏手柄、麻将键盘、横竖屏布局等（经典界面入口暂不提供；灯控 CLI 暂关以免黑屏）。

两款都**不顶替**手机里已安装的官方 MAME4droid，可同时安装。

---

## 一句话定位

在开源街机模拟器 MAME4droid 之上，为街机麻将做的飞剧场特供版。  
**基础飞剧场**降低入门门槛；**飞剧场怀旧麻将**把麻将体验做到更好。

## 两款分别怎么说

### 基础飞剧场

**一句话：** 尽量贴近官方原版，只加真正必要的便利——麻将按键包开箱即用，选游戏文件夹也不用钻设置。

用户能直接感到的：

- 多了一套麻将按键包，装好后不用自己折腾相关资源
- **打开就是官方风格的游戏列表**（与原版 MAME4droid 一致，没有自制选台页）
- 主界面顶中 📁 / 🖼：一键设 ROM 路径、导入或查看 snap
- **没有进阶版那些麻将专用界面改动**（无工具箱、无通用麻将键盘、无强制藏手柄等）
- 帮助里可打开官网，并能看到开源地址

适合：第一次用、只想少踩坑、或希望界面仍像官方的用户。

### 飞剧场怀旧麻将（进阶版）

**一句话：** 为街机麻将锦上添花——选台直开、少挡画面、好操作、带通用麻将键盘。

用户能直接感到的：

- 同样含按键包；**打开先到麻将选台列表**（可搜索、最近玩过、缺 ROM 可辨认、可紧凑），点一下进游戏，退出回到选台
- 第一次会引导选择 ROM 文件夹，并可选择导入封面图
- 选台页右上角菜单：ROM / Snap / 紧凑列表 / 设置 / 帮助
- 右上角 🧰 可收放菜单（🎮手柄 / 🀄麻将键 / ☰菜单 / 🚪退出 / 📁ROM / 🖼️snap；选游戏时可见路径项）
- 麻将键盘「更多」页有 Tab，可开关游戏内 MAME 菜单；横屏不再显示 Start/Coin/Option/Exit 四角按钮（竖屏仍保留）
- 一键藏起屏幕手柄，画面更干净；需要时再显示
- 藏起手柄后仍有菜单入口，不会没法进设置
- 通用麻将虚拟键盘：吃碰杠听和与开始/翻转/押注/投币常驻（横屏贴游戏画面左右、竖屏底栏）；横屏底栏「打牌…字母…更多」、竖屏「打牌/更多」与吃碰杠同行；只切换字母数字；很多没有专用按键包的麻将游戏也能点着玩
- 横竖屏更贴麻将：方向变化时布局会跟着调；部分竖版机台更适合竖着玩
- 横屏按键挪到四角，中间留给牌面
- 帮助里同样有官网与开源说明

适合：经常玩街机麻将、愿意为更好手感升级的用户。

## 必须说清楚的边界

- **不自带游戏 ROM**；游戏文件需用户自行合法准备
- **不是官方原版** MAME4droid，是飞剧场在开源项目上做的特供版
- **仅标准安卓**（能装 APK 的系统）；**苹果 iOS、华为纯血鸿蒙（HarmonyOS NEXT）无法安装**
- 分发或售卖时，**下载页请同时附上 GitHub 源码链接**（见开源与合规文档）
