# 整合按键包 + 透视：不要丢内容（必读）

发 APK、同步 pack、往 `mame_current` 拷 Lua 之前先看这一页。  
**按键包、灯控、透视可以同时存在。** 丢内容几乎都是整目录覆盖盖掉了「另一边才有的文件或段落」。

更细的三仓职责表也在透视仓：`D:\Dev\arcade-mj-enhance\飞剧场整合注意.md`。

---

## 三仓各管什么

| 仓 | 路径 | 主源（冲突时听谁） |
|---|---|---|
| 按键包 | `D:\Dev\MAMEmjKey\MAME_Mahjong_Mods` | `artwork`、灯控 `fei_mj_lamps/*.lua`（`tenkai.lua`、`output_proxy.lua` 等） |
| 透视 | `D:\Dev\arcade-mj-enhance` | `rbmk_wall.lua`、`ui_tiles.lua`、`art/tiles/`、`art/buttons/`、`rbmk.lua` 里的 `hunt(machine)` |
| 飞剧场 | 本仓 `assets/mahjong_pack/` | **合并结果**；`master_lamps.lua` 还必须含手机横竖屏桥接 |

入口永远只有一份：`autoboot_script master_lamps.lua`（写在 `ini/<rom>.ini`）。  
不要第二个 boot 脚本，不要选台直启挂全局 `-autoboot_script`（会黑屏）。

---

## 严禁（会丢内容）

1. **不要** `xcopy` / 整目录覆盖 `fei_mj_lamps/`  
   透视仓盖灯控 → 丢掉 `tenkai.lua` 等；灯控盖透视 → 丢掉 `rbmk_wall.lua`。
2. **不要** 用 Mods 或透视仓的 `master_lamps.lua` **整文件**覆盖 pack  
   会丢掉 `apply_device_orientation_view`（读 `.device_orientation` 切横竖屏 View）。
3. **不要** 手改 pack 后，再跑同步却不叠回透视。  
   `sync-mahjong-pack.py` 会先 **删掉整个** pack 的 `fei_mj_lamps/` 再从 Mods 拷入。脚本应随后 **自动叠回** 透视文件；若你改了脚本、跳过叠回，透视会消失。
4. **不要** 用透视仓整份 `rbmk.lua` 盖掉 Mods 版，或反过来整份盖掉带 `hunt` 的版。  
   Mods 管强制麻将控件 + 灯口；透视只加 `loadfile(rbmk_wall.lua)` + `hunt(machine)`。

---

## 正确做法

### 日常发 APK（推荐）

```
python android-MAME4droid/scripts/sync-mahjong-pack.py --check
python android-MAME4droid/scripts/sync-mahjong-pack.py
```

脚本应做到：

1. 灯控整目录来自 Mods（保证闪灯不落后）
2. `master_lamps.lua` = Mods 主干 **合并** 横竖屏桥接（不是裸拷）
3. **叠回** 透视：`rbmk_wall.lua`、`ui_tiles.lua`、`art/tiles/`、`art/buttons/`，保证 `rbmk.lua` 仍调用 `hunt(machine)`，并把 Mods 的 `rbmk/default.lay` + 按钮 PNG 盖进 pack 的 `artwork/rbmk/`

若本机没有 `D:\Dev\arcade-mj-enhance`，同步日志会写 `skip peek overlay`，pack 里就不会有透视（灯控仍在）。这是路径问题，不是「可以整目录手拷」。

### 只往 PC MAME 加透视

只拷这些文件到 `mame_current`，**不要**整夹覆盖：

- `fei_mj_lamps/rbmk_wall.lua`
- `fei_mj_lamps/ui_tiles.lua`
- `fei_mj_lamps/art/tiles/`（可空）
- `rbmk.lua`：保留 Mods 灯控，补上 `hunt(machine)`

`master_lamps.lua`：PC 上若本来就能闪灯，不要覆盖。

## 同步后自检（缺一项就是丢了）

| 层 | 必须还在 |
|---|---|
| 闪灯 | `fei_mj_lamps/output_proxy.lua`、各机 `tenkai.lua` 等 |
| 横竖屏 | pack 的 `master_lamps.lua` 含 `apply_device_orientation_view`、`.device_orientation` |
| 透视 | `fei_mj_lamps/rbmk_wall.lua`、`ui_tiles.lua`、`art/tiles/`、`art/buttons/` |
| rbmk 皮肤钮 | `artwork/rbmk/peek_*.png` 等，`default.lay` 有 `btn_peek`（**无 inputtag**）；`Portrait_2_Rows` 须有 `<bounds 1000×1640>`，否则标记钮会把竖屏撑出右边黑条 |
| rbmk | `rbmk.lua` 里有 `hunt(machine)`，且仍有 `set_value("lamp_hint_…")` |
| 入口 | 仍是唯一的 `autoboot_script master_lamps.lua` |

发 APK 前：`--check` 通过即可打；改 lay/Lua 后必须重打 APK。不要用透视仓整盖 `fei_mj_lamps`，不要裸盖 `master_lamps.lua`。pack 版本以 `mahjong_pack/VERSION.txt` 为准（透视 HUD 线约 `20260825.12`）。App 的 `versionName`/`versionCode` 只有发新公开版才需要 bump。

实机：有闪灯的机（如天开眼）灯还在；`rbmk` 上 Ctrl+9 透视还在；手机转屏切 View 还在。
