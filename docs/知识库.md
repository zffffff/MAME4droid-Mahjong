## 3. 关键代码入口

### 启动与安装

`MAME4droid.runMAME4droid()` 大致顺序：

1. `copyFiles()` / `removeFiles()`（上游逻辑）
2. **`AssetPackInstaller.installAllIfNeeded()`** — 合并按键包
3. `Emulator.emulate(...)`

安装根目录：`MainHelper.getInstallationDIR()`  
通常为：

`/storage/emulated/0/Android/data/com.feijuchang.mahjong/files/`

### 麻将体验

| 类 | 职责 |
|----|------|
| `AssetPackInstaller` | VERSION 门控复制 `assets/<pack>/` → files；标记 `.asset_packs/<id>.version`；同步 `ini/mame.ini` → 根 `mame.ini` |
| `MahjongExperienceHelper` | 默认偏好种子、方向桥接文件、强制竖屏 ROM、悬浮「隐藏手柄/菜单」 |
| `InputHandler` | 手柄隐藏 + Touch UI 时走触控，不误弹全屏 Option 对话框 |
| `MainHelper.updateMAME4droid` | 横竖屏切布局；尊重 `isOscForceHidden()`，避免隐藏后又被偏好强制显示 |

### Lua / 按键包

- `assets/mahjong_pack/master_lamps.lua`：读 files 下 `.device_orientation`（`portrait` / `landscape`），自动切 `Portrait_*` / `Landscape_*` artwork View
- `MahjongExperienceHelper.syncOrientationBridge()` 负责写该文件

## 4. 默认偏好（增量种子）

`MahjongExperienceHelper.seedDefaultsIfNeeded()` 用 `mahjong_defaults_v1/v2/v3` 标记，**只对新用户或未打标设备生效**：

- Touch UI 开
- 数字十字键（D-Pad），不隐藏 stick
- 面键数量 2（横屏 A/B）

新增默认时请 bump 新 `PREF_SEEDED_Vn`，不要改写已存在用户的偏好。

## 5. 横屏虚拟手柄布局

文件（`raw/` 与 `raw-large/` 需同步）：

- `controller_landscape.txt`（约 5:3）
- `controller_landscape_16_9.txt`
- `controller_landscape_19_9.txt`

当前约定（全屏四角，中间留给麻将画面）：

- **左上**：方向键（DPAD）
- **左下竖排（上→下）**：Start → Coin → Option → Exit
- **右下**：B 在上、A 在下
- **右上**：留给悬浮「隐藏手柄 / 菜单」（不要把 Option 再放右上挡按钮）

按钮 ID 以代码为准（`IController`）：

- `8` = Coin，`9` = Start（上游部分注释写反，勿跟错）

布局格式：`type,id,x,y,w,h`；`type 1` 为画布主矩形，横屏 `InputView` 全屏并按主矩形比例缩放。

## 6. 悬浮按钮

`MahjongExperienceHelper.attachControllerToggle`：

- 「隐藏手柄 / 显示手柄」：设 `oscForceHidden`，再 `updateMAME4droid()`
- 「菜单」：`Emulator.setInOptions(true)` + `DIALOG_OPTIONS`（隐藏手柄后仍可进 Option）
- 样式：圆角 + 背景 `0x99000000`（约 60% 不透明）

隐藏手柄后点画面：Touch UI 开启时应走 `touchPointer`，**禁止**再弹 `DIALOG_FULLSCREEN` 兜底菜单。

## 8. 核心 so 与 CI

- 完整核心 `libMAME4droid.so` **不在仓内**（jniLibs 忽略 `*.so`）
- CI / 本地用 `android-MAME4droid/scripts/fetch-mame-lib.sh` 从上游 Release APK 抽取
- 工作流：`.github/workflows/build.yml`
  - 触发：**仅手动** `workflow_dispatch`（push / PR 不会打包）
  - 入口：GitHub → Actions → **Build APK** → **Run workflow**
  - 产物：Artifacts `MAME4droid-Mahjong-debug` / `MAME4droid-Mahjong-release`
- 上游版本环境变量：`MAME4DROID_UPSTREAM_VERSION`（当前与 `1.37.6` 对齐）

公开仓库使用 GitHub Actions 一般可免费打包；需要安装包时再手动跑，避免每次提交都构建。

APK 归档名：`FeiJuchang-Mahjong-<versionName>`（见 `app/build.gradle` `archivesName`）。

## 10. 常见坑

1. **隐藏手柄立刻又出现**：必须走 `oscForceHidden`，不能只靠 `changeState()`。
2. **隐藏后点屏弹菜单**：`InputHandler` 在 OSC 关闭时要优先 Touch UI，不要 `DIALOG_FULLSCREEN`。
3. **隐藏后没有 Option**：必须保留悬浮「菜单」。
4. **改横屏布局只改 raw**：大屏可能走 `raw-large`，两边一起改。
5. **Coin/Start ID**：以 `IController` / `getButtonValue` 为准（8 coin / 9 start）。
6. **按键包不更新**：检查 `VERSION.txt` 与 `.asset_packs` 标记；必要时清 App 数据或 bump VERSION。
7. **本地缺 so**：先跑 `fetch-mame-lib.sh` 再 assemble。
8. **PowerShell 改中文 XML**：易乱码；用编辑器 / Python UTF-8 写 strings。
