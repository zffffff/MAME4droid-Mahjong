### 2.1 同步按键包（推荐流程）

脚本：`android-MAME4droid/scripts/sync-mahjong-pack.py`

**打包前先检查**（只读，不拷文件）：

```
python android-MAME4droid/scripts/sync-mahjong-pack.py --check
```

退出码 0=已对齐，1=落后于 Mods（应同步后再打 APK），2=本机没有 Mods 目录。用户明确说「这次先不动按键包」时可以跳过同步，但检查结果仍应写进发版说明。

同步：

```
python android-MAME4droid/scripts/sync-mahjong-pack.py
```

| 步骤 | 做什么 |
|------|--------|
| 1 | 确认 Mods 已含目标改动（Lua、`fei_mj_lamps`、`白名单.txt` 等） |
| 2 | 确认 `mame_current/artwork` 可访问且白名单机种目录齐全 |
| 3 | 无 `--check`：同步 Lua / artwork 并合并横竖屏桥接 |
| 4 | 检查 `mahjong_pack/VERSION.txt`（同日再同步会变成 `.2` `.3`） |
| 5 | 若需发 APK：bump `app/build.gradle` 的 `versionName`/`versionCode`（如 `1.38.1-mj2`），并更新日志/宣传/用户说明 |

脚本会做：

- 整目录覆盖 `fei_mj_lamps/`（含 `output_proxy.lua` 等）——这会暂时清掉 pack 里的透视文件
- **随后从 `D:\Dev\arcade-mj-enhance` 叠回** `rbmk_wall.lua`、`ui_tiles.lua`、`art/tiles/`，并给 `rbmk.lua` **合并** `hunt(machine)`（不整文件覆盖灯控段）
- 从 Mods 的 `master_lamps.lua` **合并** Android 横竖屏桥接（`apply_device_orientation_view` + `.device_orientation`），再写回 pack（**勿直接拷贝** Mods 版覆盖，否则丢失手机切 View）
- 按 Mods `白名单.txt` 同步 `artwork/<rom>/`；删掉 pack 里已不在白名单的机种目录
- bump `VERSION.txt`；断言 `output_proxy`、方向桥接、以及（若透视仓存在）`rbmk_wall` + `hunt(machine)` 仍在

**脚本不改动**（需手动维护）：`mame.lst` / `arcade.lst`、`ini/`、`README.txt`、`LICENSE.txt`。新增机种时记得补中文名 lst。

**不会动仓库 A 的 `release/`**：同步只读写本仓 `assets/mahjong_pack/` 与 Mods / `mame_current/artwork`。不要误以为打包会删掉或搬走 `D:\Dev\MAMEmjKey\release\飞剧场-…-日期`；若该目录不见了，查本机其它操作或是否尚未一键发布。

## 3. 关键代码入口

### 启动与安装

`MAME4droid.runMAME4droid()` 大致顺序：

1. `copyFiles()` / `removeFiles()`（上游逻辑）
2. **full**：`AssetPackInstaller.installAllIfNeeded()`（完整包 + **per-game 灯控 ini**）→ `Emulator.emulate(...)`
3. **basic**：`prepareBasicClassicBoot()`（剥 `system_names`/`mame.lst` 等污染）→ `emulate`；约 2s 后后台 `installAllIfNeeded()`（artwork + 灯控 ini）

**勿**在选台直启或全局 CLI 挂 `-autoboot_script`（会黑屏）；灯控靠 `ini/<rom>.ini` 的 `autoboot_script master_lamps.lua`（**两版相同**）。

安装根目录：`MainHelper.getInstallationDIR()`  
**预期**（外部应用目录，文件管理器通常可见）：

`/storage/emulated/0/Android/data/<包名>/files/`  
- full：`.../com.feijuchang.mahjong/files/`  
- basic：`.../com.feijuchang.mahjong.basic/files/`  

两版是两个 `applicationId`，数据目录彼此独立，属正常。

**与 ROM 路径的区别**：用 SAF / 工具箱「指定 ROM」时，zip 仍在用户选中的外部文件夹；`getInstallationDIR()` 主要放 cfg、nvram、snap、按键包、`mame.lst` 等，不等于 ROM 目录。

**路径修复（mj16）**：`UNDEFINED` 时默认走 `getExternalFilesDir`；若 prefs 已锁在 `/data/user/0/.../files/`（内部私有、文件管理器不可见），启动时自动迁到 `Android/data/.../files/`。指定 ROM /「应用默认位置」会清空错误的 `PREF_INSTALLATION_DIR` 再重算。

**中文列表（选台）**：`MahjongCatalog` 读 **APK assets** 的 `mahjong_pack/mame.lst`，与安装目录 `files/mame.lst` **无关**。两版选台均显示中文机种名。

**经典 MAME 列表（暂不用）**：1.38.3 上 `ui.ini` 的 `system_names mame.lst` 会导致经典前端黑屏或写了也不刷新列表（basic16–21 已证伪）。勿再尝试会话内热载或 `EXIT_GAME` 强刷。

### 选台页（两版 LAUNCHER）

`GamePickerActivity` 为 **full / basic** 桌面入口（`src/full`、`src/basic` 各自挂 LAUNCHER）。

点机种带 `EXTRA_ROM` + `EXTRA_FROM_PICKER` 进 `MAME4droid`；退出用 `Emulator.requestExitToPickerOrFinish()`，不 `killProcess`。

- 首次无 ROM 文件夹：引导选文件夹 → 可选导入 snap → 进列表。
- 缺 ROM：后台扫 SAF/目录里的 zip/7z，标「缺 ROM」。
- 最近玩过最多 3 条置顶；菜单：ROM / Snap / 紧凑列表 / 设置 / 帮助（**无「经典界面」**，basic24 起暂关）。

### 两版差异（门控）

| 能力 | full | basic |
|------|------|-------|
| 桌面入口 | 选台 `GamePickerActivity` | 选台 `GamePickerActivity`（basic23+） |
| 中文机种名 | 选台 `MahjongCatalog`（assets） | 同左 |
| 按键包安装 | 完整包 + **per-game 灯控 ini** | artwork + 灯控 ini（后台装）；启动前 `scrub` 污染 |
| 闪灯 / 横竖屏切 View | `master_lamps.lua`（经 per-game ini 启动） | 同左 |
| `.device_orientation` 桥接 | `MahjongExperienceHelper.syncOrientationBridge()` | **不写**（无选台外经典会话） |
| 工具菜单 + 麻将键盘 | 有 | **无** |
| 横屏 OSC | `src/full`：无 Start/Coin/Option/Exit | `main` 上游四键（选台直启后少见） |

| 类 | 职责 |
|----|------|
| `GamePickerActivity` | 选台首页：目录、搜索、最近玩过、缺 ROM、首次引导、直开 |
| `MahjongCatalog` | `mame.lst` + `groups.txt` |
| `ListArtLoader` | 行背景：定制图 → snap → `_default` → 渐变 |
| `RomFolderScanner` | SAF/目录里 zip/7z 短名 |
| `PickerSnapImporter` | 选台页导入 snap 文件夹（等价经典界面 🖼） |
| `AssetPackInstaller` | VERSION 门控复制 `assets/<pack>/` → files；标记 `.asset_packs/<id>.version` |
| `MahjongExperienceHelper` | **仅 full**：偏好种子、方向桥接、强制竖屏、工具菜单与麻将键盘（`FEIJUCHANG_FULL_UX` 早退） |
| `MahjongKeyboardPanel` | 通用麻将软键盘（打牌/更多、横竖布局） |
| `FeiJuchangPromoHelper` | 官网 / 星球链接；外开浏览器；星球复制链接并提示文件传输助手 |
| `FrontendFolderShortcutsHelper` | ROM/snap 选择对话框；basic 挂顶中芯片，full 由工具菜单调用 |
| `WebHelpActivity` | 本地帮助；http(s) 一律系统浏览器；`zsxq.com` 走星球打开策略 |
| `InputHandler` / `MainHelper` | full 下尊重 `oscForceHidden` 等 |

### Lua / 按键包 / 灯控

- **进游戏闪灯**：`AssetPackInstaller.writePerGameLampInis()` 为每个 artwork 机种写 `files/ini/<rom>.ini`（`autoboot_script master_lamps.lua` + `cheat 1`）。**full 与 basic 均依赖此路径**；full 在每次 `installAllIfNeeded()` 末尾还会 `ensureMahjongLampInis()` 重写（包 marker 已最新时也执行）。
- **全局 CLI `-autoboot_script`**：`Emulator.ensureMahjongAutobootCli()` **故意 no-op**（选台直启会黑屏）。
- `master_lamps.lua`：帧回调里 `apply_device_orientation_view` 读 `.device_orientation`，切换 Portrait/Landscape artwork View。
- **仅 full**：`MahjongExperienceHelper.syncOrientationBridge()` 在 `onCreate` / `onResume` / `onConfigurationChanged` / `MainHelper.updateMAME4droid` 写 `.device_orientation`（`portrait` / `landscape`）。**无 Lua 运行则旋转不切 View**（basic24 前 full 漏写 per-game ini 时曾出现「无闪灯 + 不跟转屏」）。
- **MAME 0.289+**：灯光走 `fei_mj_lamps/output_proxy.lua`；同步脚本须合并横竖屏桥接，勿裸拷 Mods 版 `master_lamps.lua`。
- Pack 版本：`VERSION.txt`（当前 `20260822.3`）；与 App `versionName` 独立。
- **`lhzb4` / `lhzb4dhb`**：驱动 DIP Controls 默认 Joystick 会导致 KEY 矩阵失效；`fei_mj_lamps/lhzb4.lua` 首帧置 Mahjong 模式。

## 5. 原生麻将虚拟键盘（仅 full）

类：`MahjongKeyboardPanel`（经 `MahjongExperienceHelper.attachFloatingControls`）。  
作用：按键 → `Emulator.setKeyData`，对应 MAME 默认麻将电脑键盘映射。

### 常驻动作键

| 朝向 | 布局 |
|------|------|
| **横屏** | 贴**游戏画面**左右（非屏幕最外缘），底边对齐。左：开始 / 空格 / 翻转 / 押注 / 投币 / **打牌**；右：吃碰杠听和 / **更多**。空格使「开始」与「吃」顶部对齐 |
| **竖屏** | 底栏 7 列网格：第一行开始·押注……翻转·投币；第二行打牌\|吃碰杠听和\|更多；下方字母区。整块相对底边上移约 1 格按键高 |

「打牌 / 更多」只切换字母数字区，动作键常驻。

### 字母区

- **打牌**：A–N；横屏等分对齐游戏宽度，N 权重约 2（手牌区常见宽牌），键间距 1px；键高约 2/3、更透
- **更多**：补数字字母 + 海底/大小；**Tab** 在海底前，发 `KEYCODE_TAB` 开关游戏内 MAME 菜单；横屏可横滑，高度/透明度与打牌页统一

根布局为穿透式 `PassThroughFrameLayout`（空白不挡触摸）。

## 9. 核心 so 与 CI

- 完整核心 `libMAME4droid.so` **不在仓内**（jniLibs 忽略 `*.so`）
- CI / 本地用 `android-MAME4droid/scripts/fetch-mame-lib.sh` 从上游 Release APK 抽取
- 工作流：`.github/workflows/build.yml`
  - 触发：**仅手动** `workflow_dispatch`
  - 可选 flavor：`basic` / `full` / `both`；**只打 release**
  - 入口：GitHub → Actions → **Build APK** → **Run workflow**
  - Artifact：`FeiJuchang-full-release` / `FeiJuchang-basic-release`
- **App 版本名 ≠ so 拉取版本**（可解耦）
  - `app/build.gradle`：`versionName` 如 `1.38.1-mj2`（飞剧场发版线）
  - `MAME4DROID_UPSTREAM_VERSION`：当前默认 **`1.38.3`**，只决定下载哪份上游 APK 抽 `libMAME4droid.so`
  - 核心仍为 **0.289** 时，Java 可停在已合并的 `1.38.1` 树，仅把 so URL 指到仍有资源的最新 tag
- compileSdk：上游为 37；CI 暂用 **36**（`platforms;android-37` 未上架时），`targetSdk` 仍为 **37**（含 Android 17 局域网权限）

公开仓可免费手动打包；分发 APK 的页面请同时写上本仓库 GitHub 链接。

APK 归档名：`FeiJuchang-<versionName>`（见 `app/build.gradle` `archivesName`）。

**CI 踩坑（so 404）**：上游 Release 可能删掉旧 tag 资源。`fetch-mame-lib.sh` 形如  
`…/releases/download/v${VERSION}/MAME4droid.2026-${VERSION}-release.apk`  
若 404：到 [seleuco/MAME4droid-Current/releases](https://github.com/seleuco/MAME4droid-Current/releases) 看最新仍有 asset 的版本，同步改 `build.yml` 与 `fetch-mame-lib.sh` 的默认 `MAME4DROID_UPSTREAM_VERSION`（或 workflow 入参覆盖）。

**Actions 存储**：一对 APK artifact 约数百 MB。建议**只保留最新成功构建**的 `FeiJuchang-*-release`，旧 run / artifact 用 `gh api -X DELETE …/actions/artifacts/{id}` 或 `gh run delete <run_id>` 清掉，避免配额不够。

## 12. 常见坑

1. **basic 被 full「感染」**：UX 必须 `FEIJUCHANG_FULL_UX` 早退；四角布局必须在 `src/full`，不能放 `main`。
2. **隐藏手柄立刻又出现**：必须走 `oscForceHidden`，不能只靠 `changeState()`。
3. **隐藏后点屏弹菜单**：`InputHandler` 在 OSC 关闭时要优先 Touch UI。
4. **隐藏后没有 Option / Exit**：工具菜单须保留 ☰ 与 🚪。
5. **改横屏布局只改 raw**：大屏可能走 `raw-large`，`src/full` 两边一起改。
6. **Coin/Start ID**：以 `IController` 为准（8 coin / 9 start）。
7. **按键包不更新**：发 APK 前跑 `--check`；对照 Mods `fei_mj_lamps`、白名单与 `release/` 日期；装好后还要看 `VERSION.txt` 与 `.asset_packs` 标记。
8. **本地缺 so**：先跑 `fetch-mame-lib.sh` 再 assemble。
9. **PowerShell 改中文 XML**：易乱码；用编辑器 / Python UTF-8 写 strings。
10. **横屏侧栏贴屏幕边缘**：须按 `emuView` 定位贴游戏画面，并底对齐。
11. **full 工作目录曾进 `/data/user/0/...`**：mj16 起自动迁到 `Android/data/.../files/`；若仍见旧路径可清数据或重装。
12. **中文机种名**：在**选台**（assets `mame.lst`）；**勿**再向 install-dir `ui.ini` 写 `system_names`（1.38.3 经典列表会黑屏/卡死，含游戏内「选择新系统」）。
13. **同步后丢横竖屏切 View**：说明用了未合并的 Mods `master_lamps.lua`；必须用 `sync-mahjong-pack.py` 或手工保留 `apply_device_orientation_view`。
13b. **同步后丢掉透视 HUD**：说明只拷了 Mods、没叠回 `arcade-mj-enhance`；见 [整合勿丢内容.md](整合勿丢内容.md)。不要用透视仓整目录盖 `fei_mj_lamps`（会丢灯控）。
14. **CI 拉 so 404**：上游旧 Release 可能已下架；抬高 `MAME4DROID_UPSTREAM_VERSION`（见 §9），不必强行等于 `versionName` 前缀。
15. **artwork 缺机种**：查 Mods `白名单.txt` 与 `mame_current/artwork/<rom>` 是否存在；脚本会打印 `missing`。
16. **选台把全部标成缺 ROM**：`RomFolderScanner` 失败必须返回 `null`（未知），不能返回空集；空集只表示文件夹里真的没有 zip。
17. **个别 zip 假缺（如 `lhb.zip`）**：部分 SAF 提供方把可浏览的 zip 报成目录。文件名是 `.zip`/`.7z` 时必须记为 ROM，不要当文件夹往里走。
18. **选台后进经典界面又要选 ROM 文件夹**：mj11 起进阶版已去掉经典入口；若再做类似切换，不要把 `PREF_INSTALLATION_DIR` 清掉。
19. **只有 lst 第一条（龙虎榜 `lhb`）缺底图又假缺 ROM**：`mame.lst` 带 UTF-8 BOM 时，Java `UTF_8` 读出来短名是 `\uFEFFlhb`，对不上 `lhb.webp` / `lhb.zip`。读 lst 必须剥 BOM；文件本身也不要带 BOM。
20. **怀疑 APK 按键包与 `release/` 不一致**：按 §2.2 核哈希；`master_lamps` 有桥接、pack 多 lst/LICENSE/`VERSION` 属正常。同步脚本**不会**删 `release/` 文件夹。
21. **Actions 空间不够**：旧 artifact/run 未删；保留最新成功构建即可（见 §9）。
22. **勿再做选台↔经典热切换**：曾用空串清 ROM、Alarm+`killProcess` 冷启动，表现为闪退/黑屏。mj11 起 **basic=经典首页、full=仅选台**，两边不要互相跳前端。
23. **按键包 stub `mame.ini` 勿镜像到根目录**：pack 的 `ini/mame.ini` 只有 `autoboot_script`/`cheat` 两行。若拷成 `files/mame.ini`，经典前端会黑屏（手柄/OSC 仍在）。灯控用 CLI `-autoboot_script master_lamps.lua`；安装时若发现 stub 根 ini 则删除。**也不要安装 `ini/` 目录 stub。**
24. **选 ROM 后勿长时间留下 `PREF_INSTALLATION_DIR=null`**：清完必须马上 `getInstallationDIR()` 写回；`initMame4droid` 只看 `PREF_ROMsDIR==null` 才弹首次对话框，否则会「指定两次 ROM 文件夹」。
25. **勿在首次启动前写只有 `system_names` 的 stub `ui.ini`**：会让经典系统列表黑屏。等 MAME 自己写出完整 `ui.ini` 后再合并 `system_names`；发现 stub 则删除。灯控 Lua 勿在顶层 `loadfile(output_proxy)`，等离开 `___empty` 再加载。
26. **经典前端不要挂 `-autoboot_script`**：与 `___empty` 组合时，本移植上会出现「整块黑屏 + OSC/📁 仍在」。灯控只在有 `GAME_SELECTED`（选台直启）时注入；列表进游戏的灯控需另做安全延迟加载。前端 `measureWindow` 对非游戏态强制 `STRETCH`，防止 GL 视图被量成约 1px。
27. **基础版与进阶版灯控路径须一致**：均靠 `ini/<rom>.ini` 启动 `master_lamps.lua`。**勿**只对 basic 调 `writePerGameLampInis`；full 漏写会导致无闪灯且 `.device_orientation` 桥接不生效。
28. **进阶版「经典界面」暂勿加回**（basic24）：从游戏退出后再进经典会误回上一局；且 `system_names` 与 1.38.3 经典前端不兼容。选台直启 **勿**挂全局 `-autoboot_script`。
29. **1.38.3 经典列表中文名已放弃**：`basic_cn_ready` 探针可证文件写入成功但列表仍英文；勿用 `EXIT_GAME` + reinit 强刷（弹退出确认、体验差）。
30. **基础版 LAUNCHER 已改为选台**（basic23+）：勿再在文档/规则里写 basic=经典首页。
31. **经典前端黑屏（非 in-game）**：剥空 `system_names`、删 stub `ui.ini`/`mame.ini`；`MainHelper.measureWindow` 对 `!isInGame()` 强制 `STRETCH`（防 1px GL）。
32. **同仓双线已结束**（mj20）：`line-basic` / `line-full` 合回 **`main`**；日常只维护 `main` + flavors。退出回选台用 `requestExitToPickerOrFinish()` **勿** 2s 强杀 `finish()`（会误回上一局）。
33. **进阶版会话内「选择新系统」卡死**：full 曾在 install 时写 `system_names mame.lst`，basic 在 `emulate` 前剥毒故正常。mj21 起 full 亦在 `emulate` 前 `prepareClassicFrontendBoot()`。
