## 3. 关键代码入口

### 启动与安装

`MAME4droid.runMAME4droid()` 大致顺序：

1. `copyFiles()` / `removeFiles()`（上游逻辑）
2. **`AssetPackInstaller.installAllIfNeeded()`** — 两版都装按键包
3. `Emulator.emulate(...)`

安装根目录：`MainHelper.getInstallationDIR()`  
**预期**（外部应用目录，文件管理器通常可见）：

`/storage/emulated/0/Android/data/<包名>/files/`  
- full：`.../com.feijuchang.mahjong/files/`  
- basic：`.../com.feijuchang.mahjong.basic/files/`  

两版是两个 `applicationId`，数据目录彼此独立，属正常。

**与 ROM 路径的区别**：用 SAF / 工具箱「指定 ROM」时，zip 仍在用户选中的外部文件夹；`getInstallationDIR()` 主要放 cfg、nvram、snap、按键包、`mame.lst` 等，不等于 ROM 目录。

**路径修复（mj16）**：`UNDEFINED` 时默认走 `getExternalFilesDir`；若 prefs 已锁在 `/data/user/0/.../files/`（内部私有、文件管理器不可见），启动时自动迁到 `Android/data/.../files/`。指定 ROM /「应用默认位置」会清空错误的 `PREF_INSTALLATION_DIR` 再重算。

**中文列表启用**：按键包安装后会写入/合并 `ui.ini` 的 `system_names mame.lst`（仅放 lst 不够，MAME 0.237+ 需此项）。

### 两版差异（门控）

| 能力 | full | basic |
|------|------|-------|
| 按键包自动安装 | 有 | 有 |
| 默认偏好种子 / 方向桥接 / 强制竖屏 | 有 | **无** |
| 右上角可收放工具菜单 + 麻将键盘 | 有 | **无** |
| 主界面 📁/🖼 | 在工具菜单内（选游戏时） | 顶中独立芯片 |
| 横屏 OSC | `src/full`：无 Start/Coin/Option/Exit（改走工具箱/麻将键） | `main` 上游官方布局含四键 |

| 类 | 职责 |
|----|------|
| `AssetPackInstaller` | VERSION 门控复制 `assets/<pack>/` → files；标记 `.asset_packs/<id>.version` |
| `MahjongExperienceHelper` | **仅 full**：偏好种子、方向桥接、强制竖屏、工具菜单与麻将键盘（`FEIJUCHANG_FULL_UX` 早退） |
| `MahjongKeyboardPanel` | 通用麻将软键盘（打牌/更多、横竖布局） |
| `FeiJuchangPromoHelper` | 官网 / 星球链接；外开浏览器；星球复制链接并提示文件传输助手 |
| `FrontendFolderShortcutsHelper` | ROM/snap 选择对话框；basic 挂顶中芯片，full 由工具菜单调用 |
| `WebHelpActivity` | 本地帮助；http(s) 一律系统浏览器；`zsxq.com` 走星球打开策略 |
| `InputHandler` / `MainHelper` | full 下尊重 `oscForceHidden` 等 |

### Lua / 按键包

- `assets/mahjong_pack/master_lamps.lua`：读 files 下 `.device_orientation`（`portrait` / `landscape`），自动切 artwork View
- **仅完整版**由 `MahjongExperienceHelper.syncOrientationBridge()` 写该文件；basic 不写，与官方行为一致

## 4. 默认偏好（增量种子，仅 full）

`MahjongExperienceHelper.seedDefaultsIfNeeded()` 用 `mahjong_defaults_v1/v2/v3` 标记，**只对新用户或未打标设备生效**：

- Touch UI 开
- 数字十字键（D-Pad），不隐藏 stick
- 面键数量 2（横屏 A/B）

新增默认时请 bump 新 `PREF_SEEDED_Vn`，不要改写已存在用户的偏好。

## 5. 原生麻将虚拟键盘（仅 full）

类：`MahjongKeyboardPanel`（经 `MahjongExperienceHelper.attachFloatingControls`）。  
作用：按键 → `Emulator.setKeyData`，对应 MAME 默认麻将电脑键盘映射。

### 常驻动作键

| 朝向 | 布局 |
|------|------|
| **横屏** | 贴**游戏画面**左右（非屏幕最外缘），底边对齐。左：开始 / 空格 / 翻转 / 押注 / 投币 / **打牌**；右：吃碰杠听和 / **更多**。空格使「开始」与「吃」顶部对齐 |
| **竖屏** | 底栏 7 列网格：第一行开始·押注……翻转·投币；第二行打牌\|吃碰杠听和\|更多；下方字母区。整块相对底边上移约 1 格按键高 |

「打牌 / 更多」只切换字母数字区，动作键常驻。

### 字母区

- **打牌**：A–N；横屏等分对齐游戏宽度，N 权重约 2（手牌区常见宽牌），键间距 1px；键高约 2/3、更透
- **更多**：补数字字母 + 海底/大小；**Tab** 在海底前，发 `KEYCODE_TAB` 开关游戏内 MAME 菜单；横屏可横滑，高度/透明度与打牌页统一

根布局为穿透式 `PassThroughFrameLayout`（空白不挡触摸）。

## 6. 工具菜单（仅 full）

`MahjongExperienceHelper.attachFloatingControls`：右上角 **🧰 / ❌** 可收放。

展开项（emoji，说明走 contentDescription）：

| 图标 | 作用 |
|------|------|
| 🕹️ / 🎮 | 隐藏 / 显示屏幕手柄（`oscForceHidden`） |
| 🀄 / 🀆 | 显示 / 隐藏麻将键 |
| ☰ | App 选项对话框（`DIALOG_OPTIONS`） |
| 🚪 | 等价屏幕 Exit：`Emulator.EXIT_GAME`（游戏中回列表，选游戏界面退出 App） |
| 📁 / 🖼️ | 指定 ROM / snap（仅选游戏界面显示） |

隐藏手柄后点画面：Touch UI 开启时应走 `touchPointer`，**禁止**再弹 `DIALOG_FULLSCREEN`。

## 9. 核心 so 与 CI

- 完整核心 `libMAME4droid.so` **不在仓内**（jniLibs 忽略 `*.so`）
- CI / 本地用 `android-MAME4droid/scripts/fetch-mame-lib.sh` 从上游 Release APK 抽取
- 工作流：`.github/workflows/build.yml`
  - 触发：**仅手动** `workflow_dispatch`
  - 可选 flavor：`basic` / `full` / `both`；**只打 release**
  - 入口：GitHub → Actions → **Build APK** → **Run workflow**
- 上游版本环境变量：`MAME4DROID_UPSTREAM_VERSION`（当前与 `1.38.1` 对齐）

公开仓可免费手动打包；分发 APK 的页面请同时写上本仓库 GitHub 链接。

APK 归档名：`FeiJuchang-<versionName>`（见 `app/build.gradle` `archivesName`）。

## 11. 游戏列表显示名（调研备忘）

列表 UI 在 **原生 MAME 内核**（`libMAME4droid.so`）内绘制，标题默认来自驱动内嵌英文 `description`。

| 途径 | 说明 |
|------|------|
| 设置「翻译 MAME 自身的菜单」 | 走 `language/*/strings.mo`，主要翻菜单文案；**街机游戏标题通常仍是英文** |
| **按键包系中文名（已做）** | `mame.lst`/`arcade.lst` 经按键包安装；并自动写 `ui.ini` → `system_names mame.lst`。覆盖按键包机种及已知克隆（约 70 条） |
| 改核心 / 打补丁 | 成本高，且与上游 so 拉取流程冲突 |
| 全库社区 lst | 可手动放入 files；本 fork **不内置**上万条全量汉化 |

真机若列表仍英文：确认 `files/mame.lst` 已存在；部分环境需在 MAME UI 中指定列表翻译文件，或再试改名为 `arcade.lst`；缺汉字时再补中文 BDF/`uifont`（当前依赖 1.37.4+ 系统字体渲染）。

麻将子集 short name ↔ 中文名以仓库内 `mame.lst` 为准；新增 artwork/克隆时请同步补行。

## 12. 常见坑

1. **basic 被 full「感染」**：UX 必须 `FEIJUCHANG_FULL_UX` 早退；四角布局必须在 `src/full`，不能放 `main`。
2. **隐藏手柄立刻又出现**：必须走 `oscForceHidden`，不能只靠 `changeState()`。
3. **隐藏后点屏弹菜单**：`InputHandler` 在 OSC 关闭时要优先 Touch UI。
4. **隐藏后没有 Option / Exit**：工具菜单须保留 ☰ 与 🚪。
5. **改横屏布局只改 raw**：大屏可能走 `raw-large`，`src/full` 两边一起改。
6. **Coin/Start ID**：以 `IController` 为准（8 coin / 9 start）。
7. **按键包不更新**：检查 `VERSION.txt` 与 `.asset_packs` 标记。
8. **本地缺 so**：先跑 `fetch-mame-lib.sh` 再 assemble。
9. **PowerShell 改中文 XML**：易乱码；用编辑器 / Python UTF-8 写 strings。
10. **横屏侧栏贴屏幕边缘**：须按 `emuView` 定位贴游戏画面，并底对齐。
11. **full 工作目录曾进 `/data/user/0/...`**：mj16 起自动迁到 `Android/data/.../files/`；若仍见旧路径可清数据或重装。
12. **中文游戏名未出现**：确认 `Android/data/<包名>/files/` 下有 `mame.lst` 且 `ui.ini` 含 `system_names mame.lst`；仅放 lst 不够。非全库汉化（约 70 条）。
