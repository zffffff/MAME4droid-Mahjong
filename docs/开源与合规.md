# 开源与合规（白话）

仓库：https://github.com/zffffff/MAME4droid-Mahjong  

本项目基于 Seleuco 的 MAME4droid（GPL）。可以卖、可以送，但要让别人能拿到对应源码。

## 你要做的（分发时）

1. **凡是放了 APK 下载链接的地方，同一页再加一行 GitHub 链接**（上面这个地址）。  
2. App 内「帮助 → 许可证」里已经写了源码地址；一般够用。  
3. 正式发版时在 GitHub **打 tag**（例如 `v1.37.6-mj4`），方便对上「这个包对应哪份源码」。  
4. **不要内置或售卖 ROM**；说明用户自备合法 ROM。  
5. **不要冒充官方** MAME4droid；本 fork 有自己的包名与名称。

## 不必开源的

GPL 要求别人拿得到 **App / 按键包对应的源代码**。定价、转化漏斗、私域运营文案**不是源码**，不必放进本仓库。不要把价格、微信号、下载直链、游戏 ROM 包写进 `docs/` 或 README。

卖或送 APK 时，下载页**仍然**要附 GitHub——收费可以，藏源码不行。

## 两个产品

| 名称 | 包名 | 内容 |
|------|------|------|
| 飞剧场怀旧麻将 | `com.feijuchang.mahjong` | 按键包 + 完整麻将体验定制 |
| 基础飞剧场 | `com.feijuchang.mahjong.basic` | **仅**自动安装 artwork 按键包（相对官方） |

两者源码都在本仓；按键包目录 `android-MAME4droid/app/src/main/assets/mahjong_pack/` 也按 GPL 开源（见该目录 `LICENSE.txt`）。

App 内「帮助 → 飞剧场」另有官网与知识星球导流（非 GPL 义务，便于用户了解进阶版）。

## 打包

GitHub → Actions → **Build APK** → Run workflow（手动）。  
可选 flavor；**只打 release**（不打 debug）。日常验收基础版时选 `basic` 即可。
