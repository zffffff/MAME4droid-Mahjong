# 飞剧场 · 更新说明（给玩家看的）

用大白话说明「装新版本后，你会感到什么不一样」。  
不写安装路径、编译之类的技术细节。

**当前推荐版本：** 飞剧场 `1.38.1-mj5`（2026 年 8 月）  
**两款 App：**「基础飞剧场」入门减负；「飞剧场怀旧麻将」进阶体验。可同时安装，互不影响。

完整技术发版记录见 [更新日志.md](更新日志.md)。

## 最近一次更新（2026-08-18 · mj5）

- **选台列表更全**：克隆版会出现在对应主档下面，字色更浅，方便区分。
- **封面图**：支持 `游戏名.png`，也支持 `游戏名/0000.png` 这种封面文件夹。
- 两版各有一张缺省底图；没专门配图时也会好看一些。
- 右上角 Snap 可以直接选文件夹导入（不用再绕到经典界面）。

---

## 上一档（2026-08-17 · mj4）

- **新选台首页**：打开 App 先看到麻将机种列表（可搜索），点一下直接进游戏；有定制底图或预览图会更好看。
- **升级安装**：用固定签名打包后，一般不用卸载重装，ROM/snap 文件夹设置会保留。
- 龙虎争霸 4 自动用麻将键（mj3）也还在。

---

## 上一档（2026-08-13 · mj3）

- **龙虎争霸 4 / 对话版**：以前默认是「摇杆」控制，手机麻将键会没反应；新版进游戏会自动切到麻将键控制，开箱就能点。

---

## 上一档（2026-08-13 · mj2）

- **按键包刷新**：灯光/触摸反馈跟新版模拟器核心更合拍，玩起来更顺一些。
- 进阶版横竖屏自动切换按键布局等能力都还在。

---

## 再上一档大更新（2026 年 8 月 · mj1）

### 游戏列表更认人

- 有按键包的麻将机（以及常见克隆版），列表里尽量显示**国内流行中文名**，少猜英文缩写。
- 装新版后打开一次即可；若仍是英文，可先完全退出再进，或清数据后重装（会重新准备按键包）。

### 文件更好找了

- 应用自己的资料夹，尽量落在手机里能用文件管理器看到的位置（一般在「手机存储 → Android → data → 对应应用 → files」）。
- 方便你自己核对封面图、配置等；**游戏 ROM 仍放在你指定的文件夹**，不会被偷偷搬走。

### 底子更新

- 跟上游模拟器大版本对齐，兼容更多机种、稳定性与联网对战相关能力也跟着进步。
- 你日常玩麻将：选 ROM、按键包、进阶版麻将键盘等，该有的都还在。

## 进阶版（飞剧场怀旧麻将）——这一阵在打磨什么

按时间从新到旧，方便对照你装的是哪一档体验：

| 你会感到的变化 | 简单说 |
|----------------|--------|
| 工具箱能退出游戏；「更多」里能开游戏内菜单 | 少摸系统按键，麻将相关操作更集中 |
| 横屏时屏幕四角少占位 | 投币、开始、选项、退出改走工具箱 / 麻将键，画面更干净 |
| 右上角工具箱可收起 | 要时再点开：手柄开关、麻将键盘、选 ROM、封面等 |
| 麻将专用软键盘 | 「打牌 / 更多」两页；吃碰杠听和等常驻；横竖屏布局不同 |
| 键盘贴游戏画面、少挡字 | 横屏左右侧栏、竖屏底栏；按手感微调过高度和间距 |
| 一键选 ROM 文件夹、导入封面 | 少翻设置；封面可拷进应用自己的封面目录 |

---

## 基础版（基础飞剧场）——这一阵在做什么

| 你会感到的变化 | 简单说 |
|----------------|--------|
| 尽量像官方原版 | 不堆进阶版那套麻将界面，怕乱的人更合适 |
| 首次打开自动装按键包 | 不用自己拷一堆按键资源 |
| 主界面有选文件夹、封面小按钮 | 减负，不改变你熟悉的操作习惯 |
| 帮助里有「飞剧场」入口 | 官网、知识星球更好找 |

基础版同样带上**中文机种名**、**资料夹更好找**、以及这次**上游大版本**更新。
