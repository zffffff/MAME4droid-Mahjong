# 飞剧场怀旧麻将 — 更新日志

本文件记录 **本 fork（飞剧场）相对上游的发版说明**。  
上游官方变更见 App 内帮助 changelog，或 [seleuco/MAME4droid-Current Releases](https://github.com/seleuco/MAME4droid-Current/releases)。

用户可感知变化见 [宣传要点.md](宣传要点.md)「近期变化」；**给玩家看的白话说明**见 [用户更新说明.md](用户更新说明.md)；开发约定见 [知识库.md](知识库.md)。

**当前版本：** `1.38.1-mj18`（versionCode 167，MAME 核心 0.289，按键包 `20260821.3`）

发版时请：bump `app/build.gradle` → 在本文件顶部追加一节 → 同步宣传要点「近期变化」与 [用户更新说明.md](用户更新说明.md) →（建议）打 Git tag。

## 1.38.1-mj18（2026-08-21）

- **同仓双线合流**：从 `v1.38.1-mj17` 分出 `line-full` / `line-basic`，验证后合回 `main`
- **进阶版**：选台直启不再挂 `-autoboot_script`（该 CLI 会导致黑屏+手柄仍在）；退出若原生卡住约 2 秒后强制回选台
- **基础版**：中文机种名改为「二次冷启动」——首次仍英文列表，MAME 写出完整 `ui.ini` 后再合并 `system_names`，下次打开才是中文（避免干净安装再黑屏）
- 灯控闪灯仍暂缓（进阶需另做游戏内延迟加载；基础仍不装 Lua）
