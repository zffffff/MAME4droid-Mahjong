## 列表背景图

放到：

`android-MAME4droid/app/src/main/assets/mahjong_list/bg/`

命名：`<rom短名>.webp`（或 `.png` / `.jpg`），与 MAME 短名一致，例如：

- `lhzb4.webp`
- `lhzb4dhb.webp`

回退：定制图 → `files/snap/<rom>.png` → 渐变色。

## 覆盖安装：固定 release 签名

当前 release 若仍用各环境自己的 debug 钥匙，**换机器 / CI 再打的包无法覆盖安装**，只能卸载（ROM/snap 路径也会丢）。

### 本机生成 keystore（只需一次）

在任意目录执行（自行改密码与 CN）：

```bash
keytool -genkeypair -v -keystore feijuchang-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias feijuchang -storepass '你的仓库密码' -keypass '你的密钥密码' -dname "CN=FeiJuchang, OU=Mobile, O=FeiJuchang, L=City, ST=State, C=CN"
```

把 `feijuchang-release.jks` 存到安全处（不要提交 Git；`*.jks` 已在 ignore 中）。

### 本机打包

在 `android-MAME4droid/` 下复制：

`keystore.properties.example` → `keystore.properties`

填入绝对或相对路径与密码。本地 `assemble*Release` 即用此签名。

`keystore.properties` 已加入 `.gitignore`，勿提交。

### GitHub Actions

在仓库 Settings → Secrets and variables → Actions 添加：

| Secret | 内容 |
|--------|------|
| `FEIJUCHANG_KEYSTORE_BASE64` | jks 文件的 base64（整文件） |
| `FEIJUCHANG_KEYSTORE_PASSWORD` | storepass |
| `FEIJUCHANG_KEY_ALIAS` | 如 `feijuchang` |
| `FEIJUCHANG_KEY_PASSWORD` | keypass |

Windows 生成 base64 示例：

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("D:\path\feijuchang-release.jks")) | Set-Clipboard
```

配置好后重新 Run workflow；之后**同一签名**的 APK 可覆盖安装，ROM/snap 的 SAF 授权与偏好会保留。

若 Secrets 未配置，CI 仍回退 debug 签名（仅便于编译，**不能**与正式包互相覆盖）。
